## 1. 这份文档存在的原因

这是一份非临床文档，用来在没有任何真实医学语料的情况下，跑通并验证知识
问答的完整链路：切分、检索、引用、拒答。它不包含任何医学结论，因此不会
被误当作诊疗依据。

当你导入了真实的授权文档之后，可以用 `disable` 命令把这份文档下线。

## 2. 导入文档的方式

把符合格式的 Markdown 文件放进 kb_docs 目录，然后运行导入命令。导入器会
检查 title、source、license_note 三个必填项，缺任何一项都会被拒绝。这是
一道人工闸门，用来防止来源不明的资料悄悄成为引用。

导入器只读本地文件，不会联网抓取任何内容。

## 3. 文档下线与删除的区别

下线会把文档标记为不可检索，片段仍然保留在数据库里，引用会失效并提示文档
已下线。删除会连同全部片段一起移除，无法恢复。需要临时停用某个版本时用
下线，需要彻底清除时用删除。

## 4. 拒答的触发条件

检索结果的最高相关度低于阈值时，系统会拒答。模型自行判断证据不足或资料
互相冲突时，系统也会拒答。模型返回的结论如果没有全部通过引用校验，整个
回答会被丢弃并转为拒答。三种情况都会显示「当前知识库无法回答」。

## 5. 日志与隐私

分析日志只记录事件类型、耗时、文本长度区间、核对项数量和拒答原因。音频、
逐字稿、病历正文都不会进入日志。会话标识经过加盐哈希，无法反推回具体会话。
提问原文默认不保存，只有在部署方开启且用户在该次提问上勾选同意时才会保存，
并且带有保留期限。
